**Illustrative example.** The project, ports, and dates below are fictional.

Suppose a project’s documentation originally says its preview runs on port **8000**, then a later configuration change moves it to **8100**.

## Current knowledge

> Project preview: port **8100**. Replaces the earlier port setting after the configuration change.

## Historical record

| Value | Status | Reason |
| --- | --- | --- |
| 8000 | Superseded | The configuration changed. |
| 8100 | Current | Supported by the updated configuration. |

A question about where to open the preview should retrieve the current value. A question about an older run should still be able to find the old value.

## What the curator must establish

The two records concern the same project and configuration. A different project using port 8000 is not contradictory evidence.

This is **supersession**: [[../memory/knowledge-consolidation|consolidation]] changes what is treated as current while [[../memory/evidence-and-history|history]] stays inspectable.
